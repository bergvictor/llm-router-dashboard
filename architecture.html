Architecture

How LLM router (https://llm-router-dashboard.pages.dev) is built, where its data lives, and how it ships.

Platform: Cloudflare Pages (static)Policy review: 2026-10-10Runtime policy: live monitor

Routing policy · 2026-10-10: Local GPU is reserved for Tinder and Snapchat. All other callers use cloud only, with no GPU fallback. The monitor shows the live policy when fresh runtime data is available.

Request path

  1. Live router monitor: spend, latency, pools and GPU. Static dashboard reading router metrics.
  2. Data arrives as JSON snapshots built on the laptop, never live secrets.
  3. Rebuild scripts regenerate the pages; the push (or direct upload) is the deploy.

Data and state

  • Static HTML/JSON in the output directory — the whole site.
  • Source data stays in the repository (data/, logs/); secrets stay out of version control.

Background work

  • dashboard_pusher.py pushes metrics.
  • Deploys via wrangler pages deploy dashboard-cloud.
