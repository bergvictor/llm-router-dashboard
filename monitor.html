search syntax — project, and every other parameter

Project is the caller — the automation that made the call (project:job_application_automation, project:freelance_automation, project:android_automation). A call that arrives with no X-Caller header and no /c/<caller>/ path prefix is shown and searched as project:unattributed rather than as a blank cell, so an unlabelled row reads as information instead of looking like a rendering fault. caller: still works.

Fields — caller task provider pool machine model reqmodel node mode kind status latency cost age id color. Numeric ones take > >= < <= != and real units. Prefix - to exclude, | for OR, "quotes" for phrases.

In History the plain words are searched server-side across full prompts and outputs; field: terms and - exclusions refine the loaded page here.
